# Weather App

A simple weather-search web app that displays current conditions for a city.

## Features

- Search weather by city
- Displays temperature, condition, humidity, and wind speed
- Handles empty searches and API errors
- Responsive layout for smaller screens

## Run

Open `weatherapp.html` in a browser.

> Note: The current implementation uses Weatherstack. For a production deployment, keep API credentials on a server rather than exposing them in browser code.
